# Правила оформления плашек цены (НЕ МЕНЯТЬ БЕЗ ПРИЧИНЫ)

Этот файл — «замок» на размеры и положение плашек. Он написан после серии правок,
которые ломали то, что уже работало. **Прежде чем что-то менять здесь, прочитай
раздел «Чего делать НЕЛЬЗЯ» и прогони тесты из раздела «Замки».**

Файл кода: `src/aldur_appraiser/ru_app.py`
Функции: `badge_row_height()`, `draw_rows()`, `measure_text_band()`, `panel_border_x()`

---

## 1. Размер плашек — ФИКСИРОВАННЫЙ

| Что | Значение | Где задано |
|---|---|---|
| Базовая высота строки | `16.0` px (для экрана 1440) | `BADGE_ROW_HEIGHT` |
| Формула от экрана (только при запуске!) | `экран / 90`, в пределах 12..34 | `badge_row_height()` |
| Высота плашки | базовая + `8.0` = **24 px** (с окантовкой видно ~26) | `draw_rows()` |
| Шрифт | `высота * 0.5` ≈ **12 pt**, не меньше 10 pt | `draw_rows()` |
| Внутренние отступы | `max(8, база * 0.45)` | `badge_pad()` |
| Иконка валюты | `высота * 0.62` ≈ 16 px | `draw_rows()` |

**Размер вычисляется ОДИН РАЗ при запуске** (от высоты экрана) и дальше не
меняется вообще: ни от кадра, ни от найденной панели, ни от рамок распознавания,
ни от количества строк, ни от номера нажатия.

Проверено тестом `fixed_size_test`: при рамках 8, 20, 40, 60 px и при панели 20, 48,
96 px размер плашек ОДИН И ТОТ ЖЕ — 114 × 26 (с окантовкой).

Текущие значения (экран 2560×1440): база 16 → высота плашки 24 px (видно ~26),
шрифт 12 pt, отступ 8 px, иконка ~16 px.

## 2. Положение плашки

### По горизонтали
* Плашка стоит **справа** от названия, в одной колонке на всю панель.
* Колонка считается по **самому длинному** тексту панели (рамка распознавания
  бывает короче названия — ей верить нельзя).
* Влево за границу текста плашка **не заходит никогда**.
  Граница: `panel.x + 1.55 * panel.w` (измерена по снимкам, совпадает с крестиком
  закрытия) — константа `PANEL_RIGHT_FRACTION`.
* Вправо ограничений нет (там свободный экран), кроме края экрана.

### По вертикали
* Ориентир — **строка ТЕКСТА**, а не рамка распознавания.
  Строка находится по «чернилам» на картинке: `measure_text_band()`.
  У двойной рамки берётся **нижняя** полоса текста (там длинное имя).
* Плашка центрируется **по центру этой строки**: сколько уходит выше, столько и ниже.
* Положение **запоминается по названию** (`row_centers` в оверлее) и не
  пересчитывается, пока список тот же. Пересчёт только при смене набора строк
  (прокрутка, другая панель).

## 3. Чего делать НЕЛЬЗЯ (на этих граблях уже стояли)

| # | Что пробовали | Чем закончилось |
|---|---|---|
| 1 | Считать размер из высоты рамки распознавания | Рамки дрожат → размер «плясал» при каждом нажатии |
| 2 | Считать размер от найденной панели (0.33 × высота заголовка) | Панель определяется по-разному → размер менялся между нажатиями |
| 3 | Уменьшить плашку до 18 px | Отклонено: «мелкая, верни как было» |
| 4 | Выравнивать по рамке (её низ/середина) | Плашка уходила ниже названия: внутри двойной рамки есть пустой отступ |
| 5 | Брать колонку по рамке своей строки | Короткая рамка → плашка вставала прямо на название или на «(3)» |
| 6 | Считать «типичную» высоту по медиане рамок панели | Одна высокая строка раздувала все плашки |
| 7 | Прятать окно перед снимком, чтобы свои плашки не мешали | Мерцание при каждом нажатии |
| 8 | Не затирать свои плашки в кадре | Распознавание приклеивало цену к названию → рамка сдвигалась |

**Вывод:** размер берём только из фиксированного значения; по вертикали — только
из измеренной строки текста; по горизонтали — только от границы панели и самого
длинного текста.

## 4. Замки (тесты). Прогонять после ЛЮБОЙ правки оформления

| Тест | Что проверяет |
|---|---|
| `fixed_size_test` | размер один и тот же при разных рамках и панелях |
| `centered_test` | центр плашки = центр строки, симметрично выше/ниже |
| `text_band_test` | строка текста находится отдельно от рамки (в т.ч. нижняя из двух) |
| `stable_center_test` | положение не меняется при дрожании рамок между чтениями |
| `double_name_test` | двойное название: по нижней строке, не «прыгает» |
| `no_overlap_test` | плашка не лезет на текст, колонка одна |
| `border_test` | не заходит левее границы панели |
| `repeat_press_test` | повторное нажатие не сдвигает рамки (плашки затираются) |
| `panel_size_test`, `layout_stability_test` | размер не «пляшет» |
| `badge_contamination_test` | свои плашки не попадают в распознавание |
| `close_check_test` | закрытие панели ловится по крестику (13 мс, 250 мс тик) |
| `layout_check_test` | кривая раскладка не показывается, кадр перечитывается |
| `tail_noise_test` | надписи интерфейса внизу панели не становятся наградами |
| `drift_test` | цена не меняется после фоновой догрузки |

Запуск всех: `py dev/probes/<тест>.py` (каждый печатает «пройдено» и код 0/1).

## 5. Прочее, что тоже нельзя ломать

* **Одна копия оверлея.** Новая копия сама закрывает прежнюю
  (`stop_previous_instance`, `stop_other_instances`). Две копии рисовали плашки
  друг поверх друга — это выглядело как «прыгающие» цены.
* **Свои плашки затираются в кадре** перед чтением (`blank_rects`) — иначе
  распознавание склеивает цену с названием.
* **Цены** берутся из игрового обменника (часовой снапшот GGG) с проверками;
  курс — оттуда же. Подробности в `RU_FORK.md`.

## 6. История правок размеров (чтобы не повторять)

Порядок событий одной сессии (2026-10-01), из-за которых «попило крови»:

1. Размер был привязан к высоте рамки строки → плашки «плясали».
2. Перевели на медиану рамок панели → одна высокая строка раздувала все.
3. Перевели на высоту панели (0.33) → менялся между нажатиями.
4. Убрали дробные отступы, выровняли по низу рамки → поехало ниже названия.
5. Выровняли по нижней строке с отступом 18 % → всё равно ниже.
6. Уменьшили плашку до 18 px → «мелкая».
7. Вернули 26 px, но центрировали по рамке → «задрал вверх».
8. **Финал:** размер фиксирован (26 px), по вертикали — центр ИЗМЕРЕННОЙ строки
   текста, положение запоминается. Тесты замков зелёные.

Итог: **не пытаться «улучшать» размер и выравнивание, пока пользователь не
попросит; любое изменение — только вместе с прогоном тестов из раздела 4.**
