# Как это работает

Подробности для тех, кто хочет понимать, откуда берутся цифры и почему
что-то работает не мгновенно. Все числа ниже — из самого кода и из замеров на
живом рынке лиги Forbidden Rites.

## 1. Что происходит по `Shift+D`

| шаг | что делает |
|---|---|
| 1 | Проверяет активное окно. Если в фокусе не Path of Exile 2 — ничего не делает, `Shift+D` остаётся обычной клавишей |
| 2 | Делает снимок экрана и ищет панель наград по шаблону заголовка |
| 3 | Распознаёт текст через `Windows.Media.Ocr`, два прохода (обычный и увеличенный), результаты сводятся построчно |
| 4 | Выбрасывает строки своих же плашек и служебный мусор, отделяет количество от названия |
| 5 | Переводит русское название в английское по словарю `assets/lang/ru_items.json` (3591 пара). Неизвестное имя на торговый сайт не отправляется |
| 6 | Берёт цену из книги цен в памяти |
| 7 | Рисует плашки поверх игры |

Камни умений в таблицах не лежат: их цена берётся с торгового сайта по одному
камню. Если у камня на экране нет свежей цены, она догружается фоном (плашка
показывает `…`), а удачный ответ сразу пишется в кэш — следующее нажатие на ту
же панель показывает цену мгновенно. Полный проход по всем камням можно
запустить вручную: значок в трее → «Сканировать все камни».

Панель не найдена — плашки скрываются, в журнал пишется `панель не найдена`.

## 2. Книга цен и два вида обновления

| | рынок | полный проход |
|---|---|---|
| что делает | тянет цены всех торгуемых предметов из таблиц | проверяет каждую награду каталога |
| сколько времени | ~12 секунд | 10–20 минут |
| сколько предметов | ~1170 | 291 награда |
| когда запускается | при старте и дальше каждые 15 минут | только вручную — пункт меню «Сканировать все камни»; сам никогда |
| где пишет | `prices-<лига>.json` | `runeshape_catalog*.json`, `runeshape_refresh_state.json` |

Цены появляются на экране сразу после рынка. Полный проход идёт фоном и только
уточняет их — ждать его не нужно.

### Порядок выбора цены

1. базовая цена **poe.ninja** для текущей лиги;
2. официальный часовой снимок обменника — только если он **ниже** базы;
3. **poe2scout** — только если там достаточный объём торговли;
4. живые лоты торгового сайта — только если они не выше базы.

Итог никогда не выше базовой цены. Если ни один источник не подтвердил цену —
строка остаётся с `?`. Подставлять цену «похожего» предмета запрещено: это
выглядело бы как настоящая цена, которой нет.

## 3. Полный проход: почему 10–20 минут

Каталог — 291 награда. Из них:

| категория | наград | запросов к торговому сайту |
|---|---|---|
| есть цена в таблицах (ninja / обменник / poe2scout) | 226 | 0 |
| камни умений и редкие предметы без табличной цены | 65 | 2 на каждый |

Ограничения самого pathofexile.com (он присылает их в заголовках ответа):

```
5 запросов за 10 секунд
15 запросов за 60 секунд
30 запросов за 300 секунд
600 запросов за 6 часов
```

65 наград × 2 запроса = 130 обращений. Делим на 30 за 5 минут — получаем
примерно 20 минут. Быстрее нельзя: при превышении сайт блокирует IP на минуты и
часы. Время уходит не на нашу работу, а на ожидание разрешённого темпа.

Прогресс виден в трее («Сканирование цен: N%») и в файле
`runeshape_refresh_state.json`. Если оверлей закрыть, проход прервётся и
начнётся заново при следующем запуске.

## 4. Папка `runtime`

Лежит рядом с EXE (или с проектом, если запуск из исходников).

| файл | зачем |
|---|---|
| `settings.json` | горячая клавиша, лига, прозрачность, экран, автоскрытие |
| `prices.json` | общий кэш рынка |
| `prices-<лига>.json` | тот же кэш отдельно для каждой лиги: цены лиг несмешиваемы |
| `runeshape_catalog*.json` | каталог наград с посчитанными ценами |
| `runeshape_refresh_state.json` | прогресс и итог последнего прохода |
| `runeshape_refresh.lock` | замок, чтобы два прохода не шли одновременно |
| `icons/*.png` | значки валют (exalted, chaos, divine, mirror) |
| `overlay.log` | журнал: всё, что делает оверлей |
| `overlay.pid`, `instances/` | следы запущенных копий |
| `last_panel.png`, `last_panel.txt` | последний кадр панели и распознанный текст — для разбора ошибок |

Удалить папку можно в любой момент: при следующем запуске она создастся заново,
цены загрузятся заново.

## 5. Права администратора

Нужны, если игра запущена от администратора. Windows изолирует окна разных
уровней прав: процесс без прав не может ни перехватить клавишу в окне игры, ни
нарисовать поверх него. Правило простое — либо обе программы от администратора,
либо обе без.

EXE собран с манифестом `requireAdministrator`, поэтому при запуске Windows
спросит подтверждение.

## 6. Как читать журнал

| строка | что значит |
|---|---|
| `окно игры: Path of Exile 2 (…)— клавиша слушается только в нём` | перехват клавиши работает |
| `панель найдена (совпадение 0.92) \| строк 5, с ценой 5` | панель распознана, все строки получили цену |
| `панель найдена … с ценой 0` | строки распознаны, но цен нет — смотрите строки `[цены]` |
| `панель не найдена — читаю весь кадр` | шаблон не совпал, включился запасной проход |
| `[цены] сохранённого кэша нет — качаю рынок` | первый запуск, идёт загрузка ~12 секунд |
| `[цены] рынок загружен: 1174 предметов за 12 c` | рынок в памяти |
| `[цены] запущен полный проход цен: --warm-gems` | фоновый проход стартовал |
| `[цены] не смог запустить полный проход: …` | проход не стартовал, причина в тексте |
| `[иконки] в кэше 4 шт` | значки валют скачались |
| `[цены] <предмет>: <ошибка>` | конкретная цена не получилась, причина названа |
| `ВНИМАНИЕ: в комплекте нет <файл>` | в сборке не хватает словаря или шаблона |

Открыть журнал: правый клик по значку в трее → «Открыть папку с логом».

## 7. Значки валют

Плашка показывает число, значок валюты и, если награда не одна, количество и
общую сумму: `6.0  (3 шт)`.

Значки скачиваются один раз в `runtime\icons` — только четыре нужные валюты, а
не все 600+ из справочника цен. Если сети нет, плашка напишет валюту текстом:
`6.0 ex`. Цена от этого не меняется.

## 8. Известные ограничения

- Только Windows: распознавание идёт через системный OCR.
- Русский клиент. Английские названия понимаются частично: словарь и шаблоны
  панели сделаны под русский интерфейс.
- Панель должна быть видна целиком. Перекрытие другими окнами и всплывающие
  подсказки мешают распознаванию.
- Предмет, которого нет в каталоге, показывается с `?`. В аудите 45 снимков
  таких оказалось 2 из 274 — «Уникальная бижутерия», её нет в справочнике.
- Курс божественной валюты меняется каждый день, поэтому цены — в экзальтах на
  момент обновления. Старый кэш намеренно не пересчитывается задним числом.
- Без сети показываются цены из последнего кэша; если кэша нет — `?`.
