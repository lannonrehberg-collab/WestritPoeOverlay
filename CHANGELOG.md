# История версий

## 0.4.0 — первая русская версия

- Русский интерфейс: настройки, трей, подсказки, сообщения — на русском.
- Распознавание русского текста панели наград через `Windows.Media.Ocr`
  (два прохода — обычный и увеличенный, результаты сводятся построчно).
- Словарь названий RU→EN: 3591 пара, по нему награда получает английское имя
  и, значит, цену. Неизвестное название не отправляется на торговый сайт.
- Цены: poe.ninja → официальный снимок (только если ниже) → poe2scout →
  живые лоты; итоговая цена не бывает выше базовой.
- Свои плашки цен у каждой строки панели, лучшая награда подсвечивается.
- Горячая клавиша `Shift+D` срабатывает только при активном окне игры:
  в других программах сочетание работает как обычно.
- Награда, которой нет в каталоге, показывается без цены (`?`), а не с ценой
  похожего предмета.
- Сборка под Windows одним файлом (`WestritPoeOverlay.exe`), проверка
  обновлений — по релизам этого репозитория.

### Ограничения

- Только Windows (системный OCR).
- Рассчитано на русский клиент.
- Панель должна быть видна целиком и не перекрыта другими окнами.
